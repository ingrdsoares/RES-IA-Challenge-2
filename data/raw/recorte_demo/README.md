# Textos de demonstração: não são fontes oficiais

Os arquivos desta pasta foram escritos à mão em `scripts/build_recorte_demo.py` para uma demonstração. Não use como fonte fiscal, nem indexe no acervo.

Exemplos do problema:

- `df-decreto-43982.md` se apresenta como Regulamento do ICMS, mas o texto oficial no SINJ institui o sistema de gestão do ISS.
- `jur-carf-pejotizacao.md` e `jur-stj-prescricao.md` não têm decisão oficial correspondente verificada.
- `cal-portaria-11460.md` descreve um calendário da RFB, mas o documento de mesmo número no acervo é uma portaria do MGI sobre feriados.

Os textos oficiais coletados estão em `backend/crawler/data`. O histórico das correções está em `docs/avaliacao-rag-2026-11-07.md`.
