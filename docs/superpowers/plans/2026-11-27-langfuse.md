# Migração de prompts para Langfuse

1. Extrair os textos atuais para um catálogo de importação. Criar somente prompts ausentes, verificar versões publicadas e manter o catálogo fora da execução da aplicação.
2. Integrar o SDK com cache e label `production`. Usar os textos carregados no cálculo do orçamento e vincular as gerações às versões realmente usadas.
3. Migrar RAG, assistente, leitura de guias e avaliação. Manter os contratos JSON e o transporte dos provedores.
4. Instrumentar execuções, recuperação, validação e gerações com metadados categóricos, contagem de tokens e duração. Excluir entradas, saídas e detalhes de exceções do exportador.
5. Rodar os testes com um cliente simulado e validar a publicação e o recebimento de traces quando houver um projeto configurado.
